# Security policy

Archive output is sensitive. Store it outside Git with access controls appropriate for private conversations. Do not attach snapshots, exports, logs, or operator summaries to a public issue.

Report source-code vulnerabilities privately through the repository host's security-advisory feature. Include a minimal synthetic reproduction; never include real browser data or encryption keys.

Capture is intentionally offline, but dependency installation is online unless a trusted wheelhouse is supplied. Verify published SHA-256 manifests before use.

The `diagnostics` output is designed to be content-free, but review it before sharing. Never substitute a support report for the untouched raw snapshot; keep a verified second copy of each browser run on separate, access-controlled storage.
